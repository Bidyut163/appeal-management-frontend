# Appeal Workflow Frontend

Frontend for a role-based appeal workflow management system built with Next.js and TypeScript.

## Features

- Role-based authentication
- Protected layouts
- Appeal filing workflow
- Verifier review workflow
- Registrar review queue
- Workflow confirmation dialogs
- Zustand-based auth persistence

## Tech Stack

- Next.js (App Router)
- TypeScript
- Zustand
- React Hook Form
- Zod
- shadcn/ui
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
